## Responsibility

`src/lib/components/ui` holds the shadcn-svelte primitives (button, dialog, popover, and the rest), one folder per primitive with an `index.ts` barrel. They are generated by the shadcn-svelte CLI and then customised with Tailwind ([ADR-0002](../../../../adr/0002-shadcn-svelte-tailwind-bits-ui.md)). Feature UI composes these primitives; app logic does not live here.

## Key files

- `src/lib/components/ui/button/index.ts`: Example of a primitive barrel: the Root component, buttonVariants and its prop types.

## Collaborators

- `src/lib/utils.ts`: cn() merges the primitives' class names.

## Gotchas

- src/lib/components/ui may not import core, features or plugins (scripts/import-graph.mjs).
- It is the one exception to the palette-class ban (palette-classes.test.ts), so edit it with the care due to generated code.
