## Responsibility

Holds `vault-v2.types.ts`, which re-exports types generated by ts-rs into `src/lib/contracts/generated/` under the `...V2` names used across the frontend. It declares no runtime code. New wire types belong in the Rust DTOs, not here.

## Key files

- `src/lib/types/vault-v2.types.ts`: Re-exports the generated contract types under the V2 names used across the app.

## Collaborators

- `src/lib/contracts`: Source of every type it re-exports.

## Gotchas

- vault-v2.types.ts documents mixed units: NoteEntryV2 and FileTaskGroupV2 timestamps are seconds, while NoteRecordV2 mtime and ctime and FileNode.modifiedAt are milliseconds. WikiLinkV2.position is a Rust UTF-8 byte offset and is not comparable with the UTF-16 offsets from the TypeScript parser.
- src/lib/types may import only types, contracts and packages (the types->lib rule in scripts/import-graph.mjs).
