This group is the top of the frontend and the thin layers around it. src/routes holds the SvelteKit pages for the two webviews: the main window, whose (app) layout calls into the composition root, and the quick-capture composer. src/lib/app is the composition root: it fills the ports that core exposes, orders vault open and close, subscribes to Tauri events and mounts the application shell. It is the only folder exempt from the outbound layer rules, so it can import core, features and plugins together, and no other file under src/lib may import it. src/lib/contracts is the typed boundary to Rust: ts-rs generated DTOs, the command and event maps, and the call() and on() wrappers that every other layer uses instead of raw Tauri calls. src/lib/utils is the shared helper layer used by core, features, plugins, app and routes, mostly pure functions plus a few modules that hold state for logging, debug output and dedupe. Dependencies run routes to app, app to core, features and plugins, and everything to contracts and utils; contracts imports no #lib module, while utils may import only utils and contracts, with the debug.ts and app-channel.ts imports of core/settings listed as known debt in src/tests/lib/architecture/layer-baseline.json.
