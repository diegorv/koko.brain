The core group holds the parts of Kokobrain that the app cannot run without: the editor tab lifecycle, the vault file tree and the two fan-out points that keep every derived index in step with note bytes and note paths, frontmatter parsing and safe rewriting, the open-vault state with its safe switch and exit sequences, persisted settings and themes, the Trash, and the CodeMirror editor itself with its live-preview layer. Most modules are plain TypeScript with a store, a service and pure logic files. Note saves, settings, the Trash and frontmatter rewrites use the Tauri fs plugin, while note and folder creation, indexing, search and the watcher go through Rust commands called with the typed call() helper. The modules depend on each other in a loose ring: editor, filesystem and vault import one another, and markdown-editor reads editor state while editor clears markdown-editor tab view state. Features and plugins plug into core through registries (note-change consumers, path-change consumers, content-invalidation listeners, after-save and note-created observers, tab-close listeners, write barriers, rule actions, fenced block renderers, the editor host) instead of core importing them, and core imports nothing from features, plugins or app. A few small modules (layout, status-bar, zoom, rule-actions) are thin shells around one store, one component or one Tauri call.
