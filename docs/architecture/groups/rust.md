The rust group is the Tauri backend crate, whose library is named kokobrain_lib. src-tauri/src is the crate root: it builds the Tauri app, registers every IPC command and all managed state, and owns the app menu, the global shortcuts, the composer window, the exit flow and the canonical event names. src-tauri/src/commands is the IPC layer: it checks arguments at the boundary and hands the work to the domain modules. The domain modules are src-tauri/src/vault (note parsing, the in-memory VaultIndex, task-line edits, the index snapshot cache and the file watcher), src-tauri/src/db (SQLite connections, schema and per-domain SQL repositories), src-tauri/src/search (pure text and hybrid retrieval logic), src-tauri/src/semantic (chunking, the ONNX embedder and reranker, model files, quantization and result filtering) and src-tauri/src/quick_capture (clipboard capture, shortcut intents and composer commands, with its own Tauri commands). src-tauri/src/utils holds shared helpers for atomic file writes, vault path validation and markdown file collection, debug logging, the main-thread heartbeat and process resource sampling. A request flows like this: the frontend invokes a command, the command reads or changes vault, db, search or semantic state, and then it emits events named in events.rs. Several DTOs are exported to TypeScript through ts-rs into src/lib/contracts/generated, and src/lib/contracts mirrors the command and event names, with parity tests in src/tests/lib/contracts.
