# 💡 Inspirations

Kokobrain started as a personal replacement for [Obsidian.md](https://obsidian.md) and grew its own ideas from there, including the note types system of [Tolaria](https://github.com/refactoringhq/tolaria).

[← Back to the README](../README.md)

## Feature inspirations

These are concept-level inspirations, mostly from Obsidian community plugins I used daily. No code was copied.

| Feature | Inspired by |
|---------|-------------|
| Collection | [Obsidian Bases](https://help.obsidian.md/bases) |
| Auto Organize | [obsidian-auto-note-mover](https://github.com/farux/obsidian-auto-note-mover) |
| QueryJS | [obsidian-dataview](https://github.com/blacksmithgu/obsidian-dataview) |
| Templates | [Templater](https://github.com/SilentVoid13/Templater) |
| Calendar | [oz-calendar](https://github.com/ozntel/oz-calendar) |
| Folder notes | [obsidian-folder-notes](https://github.com/LostPaul/obsidian-folder-notes) |
| Auto open & Pin tab | [obsidian-homepage](https://github.com/mirnovov/obsidian-homepage) |
| Types | [Tolaria note types system](https://github.com/refactoringhq/tolaria) |
| Relationships | [Portent knowledge base spec](https://portent.md) |

## Looking for something more mature?

Kokobrain is macOS only and built for one person. For a mature, cross-platform tool, try [Obsidian](https://obsidian.md) or [Logseq](https://logseq.com).
