## Expected wins (sanity-check the numbers against these predictions)

- **`updateIndexesForFile` p95 / max should drop sharply.** Phase 11.5k
  removed the synchronous TS Phase 1 (`updateIndexForFile` parsing
  wikilinks into `noteIndexStore`). The remaining work is a fire-and-forget
  Rust IPC + the surviving Phase 2 TS updaters (collection, file-icons,
  calendar). Baseline p95 was 42.8 ms with a 203 ms max tail; expect both
  numbers to compress significantly.
- **`updateActiveTabLinks` should hold or slightly improve.** Phase 11.6
  inlined the function into `+layout.svelte`, removing one function-call
  hop. The IPC fetch is unchanged. Expect ~0–2 ms drop.
- **`contentSyncEffect:noop` stays at 0 ms.** Phase 5's signal-driven
  effect already eliminated the per-keystroke toString cost; this phase
  doesn't touch the keystroke path.
- **`openFileInEditor:fresh` should hold.** The migration didn't change
  the file-open path; numbers should match baseline within noise.
