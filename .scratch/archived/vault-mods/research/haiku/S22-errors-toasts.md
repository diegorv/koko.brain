Services are expected to try/catch and propagate errors, and the caller decides what the user sees. Recommended pattern for a mod action: the host wraps the mod's entry point and each host-API call in try/catch, calls error(tag, err) for the log and Sentry, then shows one toast.error with a short human message and an optional description; it never rethrows past the modal. Precedent: meta-bind-button-widget.ts:95-141 returns false and toasts without crashing, and queryjs/kb-api.ts:401-420 catches script errors and renders them inline in the block.
