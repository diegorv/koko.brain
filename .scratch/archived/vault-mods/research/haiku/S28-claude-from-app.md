## Summary

Best fit for "a mod that runs 30 haiku + 10 opus agents and writes a PRD into the vault" is option (c), the claude CLI in headless mode (`claude -p`), spawned from a Rust Tauri command, with the Agent SDK (b) as the alternative if a Node sidecar is acceptable. Option (a), a direct browser call to the Messages API, is the weakest: the docs say browser calls need the header anthropic-dangerous-direct-browser-access: true, which exposes the API key to any mod JavaScript running in the webview, and Kokobrain's CSP connect-src (src-tauri/tauri.conf.json:29) does not list api.anthropic.com. The Agent SDK is a TypeScript package that spawns a bundled native Claude Code binary as a subprocess (installed as an optional dependency), so it cannot run in the Svelte webview and needs Node or Bun or Deno as a host process. Headless `claude -p` supports `--output-format json|stream-json`, `--json-schema`, `--allowedTools`, `--permission-mode`, `--permission-prompts none`, `--bare` and `--max-budget-usd`, and the Agent SDK supports per-subagent `model` through `AgentDefinition`. Kokobrain has no Anthropic code yet and no shell plugin, but Rust already spawns processes (src-tauri/src/quick_capture/source.rs:244 runs osascript via std::process::Command), so a Rust command can spawn `claude`. Not verified: the `--model` flag and the `haiku`/`opus` alias names (the CLI reference was not fetched), the minimum Node version (only a third-party source says 18.14.0), and whether Claude subscription login is allowed in a third-party app (the Agent SDK overview says third-party developers need API-key auth unless previously approved). Full report content is in this message only.

- The Agent SDK overview says third-party developers may not offer claude.ai login or rate limits unless previously approved, so a mod that bills through the owner's subscription is not allowed without approval: https://code.claude.com/docs/en/agent-sdk/overview
- The headless doc says bare mode ignores OAuth and the keychain and needs ANTHROPIC_API_KEY, and that without --bare a -p run executes the project's .claude/settings.json hooks and .mcp.json servers, even in an untrusted folder: https://code.claude.com/docs/en/headless
- The subagent concurrency default is 20 (CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) and depth is 3, so 40 agents need queuing, and the SDK can cap spend with maxBudgetUsd: https://code.claude.com/docs/en/agent-sdk/subagents (via third-party summary, unverified against the official page)
- The browser-direct CORS details come from Simon Willison's 2024 post and a 2026 GitHub issue, not from an official Anthropic page I could fetch. Official docs say browser requests are blocked for orgs with ZDR or Compliance API enabled: https://simonwillison.net/2024/Aug/23/anthropic-dangerous-direct-browser-access/
- Kokobrain's Tauri capabilities allow outbound HTTP only to api.todoist.com and the themes repo (src-tauri/capabilities/default.json:224-263), and the CSP connect-src names no Anthropic host (src-tauri/tauri.conf.json:29). Any direct HTTP path needs both changed, and any mod JavaScript could read the key from the webview.
