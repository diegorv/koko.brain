## Findings

1. **minor**, src/lib/features/canvas/CanvasInner.svelte:250-254 with src/lib/core/editor/editor.service.ts:240-243. An edit made inside the 300 ms debounce and then closed with `closeTab` is dropped: `removeTab` runs before the keyed instance's onDestroy, so the flush's `updateTabContentOnly(A, json)` finds no tab and nothing reaches a.canvas. The tab was not dirty yet, so the close gave no "unsaved changes" prompt either. Probed: `writeTextFile` is never called, on the branch and on main, so this is not a regression and the close criterion (no write into the neighbour) holds. It does fall short of the "What to build" wording ("an edit made just before switching or closing tabs ... is saved into that canvas's .canvas file"). Fix: a follow-up Issue. Either flush the canvas before `removeTab` (a pre-close hook the canvas registers), or have the path-scoped writer save a path with no open tab straight to disk.
2. **minor**, src/lib/features/canvas/CanvasInner.svelte:63. The same mechanism drops a pending edit when the canvas is renamed inside the debounce window: the rename re-keys the instance and the flush targets the old path, which has no tab. The build report states this. Fix: cover it in the same follow-up as finding 1.
3. **nit**, src/lib/features/canvas/CanvasInner.svelte:95,123. Switching the `flowToCanvas` base from the prop-derived `canvasData` to `lastSyncedData` has no test that fails without it. Reverting it passes all four tests even with shared node ids and unknown fields, because under Svelte 5.57 a teardown read of `jsonContent` still sees A's pre-flush value. It is the defensive change the Issue asked for and probably cannot be tested without depending on that Svelte internal. Fix: none required; optionally say in the test file's header that the base switch is not covered.
4. **nit**, src/lib/features/canvas/CanvasInner.svelte:80-83. After this change `canvasData` has only one reader, `flowState`, which nothing reads (that was dead code before). This change orphaned `canvasData`. Fix: delete both `$derived`s (and the then-unused `CanvasData` import only if nothing else uses it; `lastSyncedData` does), or leave them and list them as pre-existing dead code.
5. **nit**, src/tests/lib/features/canvas/canvas-tab-switch.test.ts:42-49. The criterion says to mock only `@tauri-apps/plugin-fs`.
