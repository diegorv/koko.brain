## Findings

1. nit, `src/lib/utils/font-stacks.ts:43`: the "already quoted" test `/^(["']).*\1$/` also accepts values that start and end with the same quote but are not one string, e.g. `"Foo" "Bar"` or `"Foo" 6 "Bar"`. They are returned unchanged, are invalid CSS, and CodeMirror drops the whole declaration, appended fallback included. Such input is unlikely (the picker supplies bare CoreText names), so no change is needed for this Issue. A fix would be to only skip quoting when the inner text has no unescaped matching quote, e.g. `/^"(?:[^"\\]|\\.)*"$|^'(?:[^'\\]|\\.)*'$/`, and add a table row.
