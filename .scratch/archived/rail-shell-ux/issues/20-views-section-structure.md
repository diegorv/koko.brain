# 20: The Views section has groups, hidden views and Move to Trash

**What to build:** Two `.view` keys and one menu item give Types > Views structure. `_group: Work` puts the view under a "Work" subheading inside Views; views without `_group` stay at the top, ungrouped. Groups sort by name and views inside a group (and the ungrouped ones) by `_order`, then label. `_visible: false` hides the view from Views (it stays a file: the folder lens lists it, and Issue 23's palette command reaches it). The view row menu gets "Move to Trash", with the same confirmation, Trash path and failure toast as Move to Trash on a note. View labels and group names sort naturally ("Week 2" before "Week 10"), like the file tree.
