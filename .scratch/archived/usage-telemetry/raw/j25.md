## Findings the scouts missed

- **M1 (info).** A content-safe local usage trail already exists. `src/lib/utils/log.service.ts:145,192-215` logs `[NAV] click "<aria-label>"` while the opt-in heartbeat runs, and never logs element text (`:204-205`). Caveat (not verified): some aria-labels may embed note names.
- **M2 (high, privacy CI).** The privacy scanner skips every line that contains a URL. The skip rule `:\s*//` (`.github/workflows/privacy.yml:69`) is matched against the whole `file:line:content` string (`.github/actions/scan-external-calls/action.yml:84-95`). Tested with BSD grep and ugrep: `await fetch('https://evil.org/c')` and `posthog.init(k, { api_host: 'https://eu.i.posthog.com' })` are both skipped. The `https?://` patterns (`:57`, `:100`) are inert. This should be its own Issue.
- **M3 (high).** Sentry cannot answer "over time": logs and metrics retention is 30 days on every plan.
- **M4 (medium).** Aptabase 1.3.0 also does crash and error reporting (`lib.rs:93,117-141`, `track_error`), which overlaps the Sentry panic hook. Keep it off if adopted.
- **M5 (low).** The plugin's reqwest has `default-features = false` and no TLS feature. HTTPS works only through feature unification with the app's `reqwest 0.13` (`src-tauri/Cargo.toml:65`). Not tested.
- **M6 (medium).** Retention ranking: Aptabase up to 5 years, TelemetryDeck free 3 months, Sentry 30 days, PostHog UNVERIFIED, self-hosted and local counters unlimited.

## Verdict for this area

A **local-only feature counter** is the best default. It needs no vendor, CSP change, PRIVACY.md change or new dependency, and it has no retention limit. Sentry fails the "over time" requirement (M3). PostHog fits worst: autocapture and remote-setting defaults, an open Tauri v2 delivery report, about 54 releases a month against a 5-day quarantine, and a heavy package.

If the owner wants a hosted dashboard anyway, **Aptabase EU** is the strongest vendor: MIT plugin, manual events only, 5-year retention, 20k events/month free. It comes with a process-wide key (switching it needs a restart), an ACL permission, a PRIVACY.md rewrite, and a duplicate crash reporter to turn off. **Self-hosted Umami** is the fallback if the data must stay off third-party clouds. Whatever is chosen, fix M2 first.

Unverified: PostHog pricing and default properties, TelemetryDeck plan details (search summary only), OpenPanel and Countly license terms. No request was captured, so the payload claims rest on reading the source only.
