# Scout 04: Rust crate and Tauri plugin compatibility with iOS (aarch64-apple-ios)

Scope: every direct dependency in `src-tauri/Cargo.toml` (kokobrain 3.0.12), versions from `src-tauri/Cargo.lock`.
Read-only. No cargo, pnpm or compile step was run.

Legend: **keep** = no change; **cfg-gate** = exclude on iOS with `cfg`/target tables; **replace** = iOS needs a different implementation.
UNVERIFIED = not confirmed by a build or by a quoted primary source.

Method notes:
- Crate sources were read at the locked tag with `gh api`. Where a tag was not reachable, the default branch is named.
- The Tauri plugin doc pages (v2.tauri.app/plugin/*) were scraped with WebFetch, and their support-level cells came back empty. The authoritative table used here is each plugin's README at the locked tag in `tauri-apps/plugins-workspace`, plus the `cfg` gates in that plugin's `lib.rs`.

## Summary

1. **Compile or runtime blockers in our own list (cfg-gate needed):** `tauri-plugin-global-shortcut` (crate excludes iOS entirely), `tauri-plugin-updater` (desktop only; its `lib.rs` header says "Supported platforms: Windows, Linux and macOS"), `tauri-plugin-process` (README: iOS unsupported), and `arboard` (no iOS clipboard backend).
2. **Product blocker, not a compile error:** folder picking. `tauri-plugin-dialog` `pick_folder` is `#[cfg(desktop)]`, and `src/lib/core/vault/vault.service.ts:26` opens the vault with `open({ directory: true })`. iOS needs a different vault-selection design (owner decision, see Open questions).
3. **File watching:** `notify` 8.2.1 builds for iOS and picks the kqueue backend. kqueue keeps one fd per watched file and has no recursive mode, so watching a large vault on iOS is a scale risk. Recursive watch call is `src-tauri/src/vault/watcher.rs:253,268`.
4. **Semantic stack (`ort`, `tokenizers`/`onig`, `ndarray`, `half`, `reqwest` model download):** an iOS prebuilt ONNX Runtime (CoreML variant) exists in the pinned `ort-sys` dist table, so it is plausible on iOS. Nothing has been built for iOS. Since semantic search may be dropped on iOS, cfg-gating the whole semantic module is the cheap default.
5. **iOS-clean as-is (by code reading):** `rusqlite` bundled (FTS5 on), `sysinfo` (has an iOS backend), `sentry` (native-tls uses Security.framework on Apple targets), `reqwest` 0.13 (rustls with iOS platform verifier), `tokio`, `image` (png only), and the pure-Rust serde/regex/chrono family.
6. **Tauri plugins usable on iOS per README:** opener (URL open only on mobile), fs (app container by default, security-scoped URLs handled, `PrivacyInfo.xcprivacy` needed), dialog (except folder picker), http, deep-link (config-only registration), clipboard-manager (plain text only).
7. **`objc2`** is `cfg(target_os = "macos")` only and all its call sites are macOS-gated. Keep as is.

## Open questions and risks

- **Vault location and picker (owner decision):** iOS folder picking is unsupported in the dialog plugin. Options: (a) vault always inside the app container (Documents), with import/export through the file picker, or (b) keep a folder picker through a different API that yields security-scoped URLs (not researched here). Trade-off: (a) is simplest and works with `fs` as documented, but loses "open an existing folder" on iOS. Ask before design.
- **kqueue on iOS:** fd-per-file means a recursive watch over a large vault may exhaust descriptors. iOS per-process fd limit: UNVERIFIED. Polling or foreground rescan is the likely replacement.
- **Semantic on device:** ORT iOS memory footprint, CoreML EP behavior, and the ~542 MB model store in the app container (ADR-0019 already flags sync conflicts) are UNVERIFIED.
- **sysinfo App Store features:** whether `apple-app-store` removes anything kokobrain uses (only `System` in `debug.rs`) is UNVERIFIED.
- **Tauri menus:** `src-tauri/src/lib.rs:153-256` builds a native menu. Menu behavior on iOS was not checked.
- **Asset protocol on iOS:** `protocol-asset` and `convertFileSrc` (`live-preview/widgets.ts`, `app/editor-host.ts`) on iOS not checked.

## Not verified

- No iOS compile of any crate (rules). "Yes" entries rest on code and README reading, not on a build.
- `arboard` X11 compile on iOS, `tauri-plugin-updater` and `tauri-plugin-process` iOS compile status, `onig_sys` on iOS, `tokio` and `notify` runtime behavior on iOS.
- `yaml-rust2` gating (repo `Cargo.toml` is a pointer file on the default branch) and `ts-rs` version pin (default branch read).
- Tauri docs tables for updater, global-shortcut, process, and http were scraped without their level column; the plugin READMEs and `lib.rs` gates are the basis for those rows.
