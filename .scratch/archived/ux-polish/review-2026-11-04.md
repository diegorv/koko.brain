# UX polish review (2026-11-04)

Lead-designer synthesis of the nine theme reports in `.scratch/ux-polish/work/` (radius, shadow, overlays, settings, layout, typespacing, color, states, views), checked against the screenshots in `references/ux-polish-2026-11-04/screens/{default,lavender}/` and against the code at `dd4f06376`. Paths are relative to the repo root. `references/` is gitignored: the screenshots, the capture spec and the ticket drafts exist only in the owner's main checkout, not in git or in other worktrees. The reference bar is Linear, Things, Craft and Obsidian at its best: quiet chrome, one shape language, surfaces that lift, motion you notice only when it is missing.

The one-line diagnosis: the app has good bones (a consistent 40px top band, a working chrome type scale, a theme builder with contrast lifting, shadcn primitives with a sound role split), but three plumbing gaps undo a lot of it. (1) No overlay animation is ever generated. (2) The app theme's light or dark mode never reaches anything that branches on mode. (3) There are no elevation tokens, so floating surfaces sink instead of lifting. Most of the visible roughness in Lavender Haze and in every menu comes from those three. The rest is drift: hand-rolled controls, one-off radii and sizes, and a Settings row component with a fixed 40% control column.

## 1. Summary: highest-impact changes, ranked by impact over effort

Every item below was re-checked in the code for this review (file:line given).

1. **Turn overlay motion on (10 min).** Nine shadcn overlay primitives use `animate-in`, `fade-in-0`, `zoom-in-95` and `slide-in-from-*` (for example `src/lib/components/ui/dialog/dialog-content.svelte:30`), but `src/app.css:1-2` imports only `tailwindcss` and katex and `package.json` has no animation package, so every dialog, menu, popover, select and tooltip pops in a single frame. Adding `tw-animate-css` revives all of them unchanged.
2. **Fix the focus fallback and the stray dialog ring (10 min).** The base layer (`src/app.css:379-382`) applies only `border-border`, so anything without its own focus style gets the WebKit system-blue ring. `dialog-content.svelte:30` has no `outline-none`, which is the blue box around File History (`default/12-cmd-view-file-history.png`). Add `outline-ring/50` to the base `*` rule and `outline-none` to dialog content.
3. **Fix the invalid meta-bind focus color (10 min).** `live-preview/styles.ts:683-684,766-767,788` use `hsl(var(--primary))`, but `--primary` is hex at runtime, so focus border, ring and checkbox accent all silently fall back. The owner uses meta-bind daily.
4. **Make the app theme drive dark mode (0.5 to 1 day).** `src/app.html:2` hardcodes `class="dark"`, `app.css` has no `@custom-variant dark`, so `dark:` follows macOS appearance. `AppOverlays.svelte:12` pins `<Toaster richColors theme="dark" />`, and `editor-theme.ts:78` registers CodeMirror with `{ dark: true }` for Lavender too. Derive `isDark` from the editor background, toggle `html.dark`, add the custom variant, and bind Sonner and CodeMirror to it.
5. **Give floating surfaces real elevation (0.5 to 1 day).** No `--shadow-*` tokens exist in `app.css`. Default `popoverBg` is `#171a26` (`theme.logic.ts:90`), darker than the `#21222e` background and the `#2a2e3d` editor, and Lavender's `#DDD8E8` (`:209`) is darker than its page and equal to code blocks and setting rows. Menus read as holes (`default/13-more-menu.png`). Add theme-aware shadow, ring and scrim variables, and derive the popover one step above the editor.
6. **Fix the Settings row and drawer chrome (half a day).** `SettingItem.svelte:21` reserves `w-2/5` for every control, which causes orphan wraps, truncated font family and a four-line build string (`default/20-settings-01-editor.png`). The drawer is pinned with inline `bottom: 24px; width: 820px` (`SettingsPanel.svelte:116`) against a `h-[32px]` status bar (`StatusBar.svelte:8`), so it overlaps the bar by 8px. Its nav and page titles sit on different baselines, and the selected nav item uses the hover color.
7. **Keep the active tab visible (2 h for the core fix).** `EditorTabs.svelte:29` is `overflow-x-auto` with no `scrollIntoView`, so the open document scrolls out of the strip (`lavender/08-canvas.png`, where `Map.canvas` is off-strip). Scroll on activation, add an edge fade, fix tab height, hide `.md`.
8. **Trim the note action bar (1 h).** Up to 10 equal-weight icon buttons. Two of them are duplicated elsewhere: Raw (`NoteActionBar.svelte:176`) duplicates the floating `<>` (`EditorView.svelte:131-142`), and the sidebar toggle (`NoteActionBar.svelte:227`) duplicates `AppShell.svelte:187-193`. Both pairs are visible in `default/01-shell-initial.png`. Remove the duplicates, fold five actions into More, and make the bar `h-10` like its neighbours (it is `h-9` at `:124`, which steps 4px against the Properties header).
9. **Repair Lavender Haze in canvas, graph and collection calendars (1 to 1.5 days).** `CanvasInner.svelte:726-743` ("Override Svelte Flow theme for dark mode") hardcodes white and black alphas. `GraphView.svelte:46-51` paints `#1a1a1e` (`lavender/12-cmd-toggle-graph-view.png` is a black slab inside a light app). The collection calendars read `var(--foreground-15, rgba(255,255,255,0.15))`, and `--foreground-15` is defined nowhere, so their grid vanishes on light.
10. **Unify list-row radius (1 h).** Left sidebar rows use bare `rounded` (4px, off the `--radius` ladder; `FilesNavigator.svelte:286`, NoteRow, TypesNavigator). The rail icon right next to them (`Rail.svelte:79`) and every right-sidebar row use `rounded-md` (8px). Add `--radius-xs`, rename bare `rounded`, and move rows to `rounded-md`.
11. **Make the theme contrast guard see everything (half a day).** The three Default overrides `oklch(0.55 0.06 268)` (`theme.logic.ts:125,132,142`) bypass `ensureContrast` because it cannot parse oklch. The test records them as expected skips (`src/tests/lib/core/settings/theme-builder.logic.test.ts:233-238`). They measure about 2.8 to 3.2:1 on their panes, which makes them the dimmest common text in the main theme. Use passing hex values, delete the skip list, and add the missing pairs (tab bar text, switch off-track, input edge).
12. **Use verb labels on native confirms (20 min).** Eight `ask()` calls (TrashSection 34/49, delete-note.service 14, editor.service 277, NoteRowMenu 142, FilesNavigator 193, FileHistoryDialog 44) show "Yes" and "No" for destructive questions. Only UpdateSection passes `okLabel` (`:207`).

Outside the polish ranking, one correctness bug must ship first: **Quick Capture loses text on a failed save.** `src/routes/composer/+page.svelte:45-50` catches the `submit_composer_capture` failure with `console.error` only, then `dismiss()` still runs, and `resetForShow()` (`:57-61`) clears the text on the next show.

## 5. What was not checked

- **Runtime environment.** All screenshots come from a mocked browser build (`references/ux-polish-2026-11-04/zz-ux-screens.spec.ts` against the Vite dev server with Playwright), not the Tauri WebKit window. Not seen: native window chrome and traffic lights, vibrancy and transparency, the native `ask()` dialogs, the Quick Capture window (transparent, OS-drawn shadow), the dock badge, and real macOS Full Keyboard Access focus traversal.
- **Fonts.** Captures use fallback fonts, so the system UI stack and the editor font (MonoLisa in the settings value) were not rendered as the owner sees them. Line breaks, truncation points and optical weight may differ.
- **Data.** The test vault and mocked IPC produce some states that may be fixture artifacts: "3 tags" over "No tags found", "1 min read" for 0 words, the theme catalog error toast, and the kanban triangles color.md could not trace.
- **OS appearance.** All captures ran with a light macOS appearance. The `dark:`-follows-OS defects (destructive button at 60%, switch thumb, ghost hover) are inferred from code, not seen.
- **Interaction.** Hover, focus and open states beyond the captured ones (`15-tab-icon-hover.png`, the menus and palettes) are from code. Escape propagation from bits-ui layers inside Settings, bits-ui focusing `Dialog.Content` in every dialog vs only those without a tabbable child, and the KanbanLane grip that probably never appears were not exercised.
- **Animation.** The missing-animation claim rests on `app.css` and `package.json` (re-checked here) and the reports' compile test; no recording was made. The `tw-animate-css` recommendation comes from memory of the shadcn-svelte Tailwind v4 setup; check its current install docs before adding it.
- **Contrast.** Ratios are WCAG math on the built theme hex values (color.md) or theme constants, not measured on screen. Catalog and custom user themes were not evaluated against the proposed ladder or the new guard pairs.
- **Not captured at all.** Expanded Heading Typography, the collection calendars in Lavender, RelationshipSearch and the kanban popovers, the composer failure path, narrow windows below 1440px, and the Welcome or vault picker screen beyond the code read.
- **Effort estimates** assume one implementer and include the frontend gate and a two-theme screenshot pass, not E2E updates for Issue 7 if Settings becomes a modal.
