# 04: Closing the main window never leaves a windowless app: Quick Capture, deep links and a Dock click keep working

**What to build:** registerCloseHandler (src/lib/app/tauri-listeners.service.ts:48-55) runs prepareForExit and then destroy()s the main window. The hidden composer window keeps the process alive (src-tauri/src/commands/app_exit.rs:46-48 says so), and the run loop (src-tauri/src/lib.rs:391-395) handles only RunEvent::ExitRequested: there is no RunEvent::Reopen handler and nothing recreates 'main'. So the Dock click shows nothing and the app looks hung until Cmd+Q. The hotkeys still fire because dispatch_shortcut only checks db::is_open() (lib.rs:45-47), but qc:capture-detected has no listener left (the only one is in the main webview, src/lib/plugins/quick-capture/quick-capture.service.ts:53-75): a clipboard capture is dropped with no feedback, and the composer times out with 'Save not confirmed'. Fix direction: on close, after prepareForExit succeeds, hide the main window instead of destroying it (add core:window:allow-hide to capabilities/default.json; core:default does not include it), and handle RunEvent::Reopen in lib.rs by showing and focusing 'main'. Cmd+Q with a hidden main window must still flush and exit (exit_decision already asks the frontend while the window exists; a hidden webview still runs). Quitting on close instead is the other option; macOS convention and the background-capture design (ADR 0028) favor hide.

**Blocked by:** none

**Status:** needs-info

**Gate:** Both: `cargo test --manifest-path src-tauri/Cargo.toml` + `pnpm check` + `pnpm vitest run`.

**Owner decision needed:** Red close button: (a) quit the app after the exit flush (invoke confirm_exit, frontend only; the Quick Capture shortcuts stop with the app), or (b) hide the main window, show it again on a Dock click through RunEvent::Reopen, and keep captures and deep links writing (Rust plus the allow-hide capability). Either way, the tests at tauri-listeners.service.test.ts:224-311 that pin destroy() change. Decide Issue 44 (Dock Quit, logout and shutdown skip the exit flush) together with this one: with (b), Dock right-click Quit becomes the natural way to quit.
