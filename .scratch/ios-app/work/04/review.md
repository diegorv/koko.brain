## Findings

1. nit, `src/lib/core/settings/settings.logic.ts:47-52` and `RemoteAccessSection.svelte:26-32`: a typed 8443 or 10000 is silently replaced with 4747. Nothing tells the owner why the value changed, so the Serve command they copy names a different port than the one they typed. Fix (optional): show a short inline note when the normalized port differs from the input.
2. nit, `src-tauri/src/remote/access.rs:77`: the login compare is exact. An owner login typed with different case than Tailscale sends (for example `Diego@Example.com`) gets 403 on every request, and only the debug log shows why. This is fail-closed by design and the troubleshooting doc covers it. Fix (optional): add "use the login exactly as `tailscale status --json` prints it" to the field description.
3. nit, `src/lib/app/remote/remote-transport.ts:171-175`: any single call slower than 30 s now ends the session and forces a reload. The criterion asks for this, and no current remote call is known to be that slow. Watch for it in the owner check on a large vault.
