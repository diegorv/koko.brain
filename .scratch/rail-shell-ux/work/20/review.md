## Probes and reasoning (no defect found)

- Group sort: the comparator in `viewNavigatorRows` returns 0 only for equal groups. `naturalCompare` falls back to a raw code-point compare, so two distinct names never compare equal. The ordering is total, each group's rows stay together, and `{#each viewSections ... (section.group ?? '')}` gets unique keys: blank groups are null, so `''` cannot clash with a real group.
- `ViewDialog`'s `existingLabels={viewLabels(fsStore.fileTree, ...)}` is a Svelte 5 lazy prop. It is evaluated only when the dialog reads it (`nameError`), so a closed dialog does not walk the tree on each tree replacement. `typeDefinitionsStore.entriesByPath` is `$state` that is replaced on every update, so label changes reach the dialog.
