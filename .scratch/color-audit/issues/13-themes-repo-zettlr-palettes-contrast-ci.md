**What to build:**

1. The Zettlr palettes (`themes/zettlr-*-dark.json`, `themes/zettlr-*-light.json`) use the border gray as `palette.hover` and `palette.selected`, so hover and selected rows are the same color as dividers and muted text fails on them. Give each its own hover and selected surface, bump each theme's `version` (minor) so installed copies are offered the update.
2. Shimmering Focus: the blockquote bar is nearly invisible; NoteInfo heading and Tags hover counts slightly under on some themes (re-measure after Issues 05 to 07, most should be fixed by the builder).
3. A CI check in the themes repo that builds every theme with the app's builder rules and fails on a `READABILITY_PAIRS` miss. Simplest path: a script that imports the pair list and builder from a pinned copy, or a JSON export of the pairs the app publishes. Decide in the ticket; keep it small.
