5. Tooling: traced every path a theme takes to the screen and ran the real code on a hostile import (b.mts).

## Findings

1. **Theme row hover state, Settings > Appearance (high).** The row's edit/duplicate/uninstall buttons exist only while the row is hovered (`opacity-0 group-hover:opacity-100`, AppearanceSection.svelte:190), so they are always drawn over `bg-settings-hover-bg` (:173). Icons use `text-muted-foreground`: 15/28 under 4.5, 5 under 3 (Zettlr dark `#8f8f98` on `#505050` 2.52 to 2.58, Lc27). Uninstall/delete X (:222,:233) turns `text-destructive` on `bg-destructive/10` over the hover bg: 22/28 under 4.5, 8 under 3 (Zettlr Bordeaux Dark `#d3322f` on `#5d4d4d` 1.62, four other Zettlr dark 1.68, KokoBrain Default 2.57, Lavender Haze 2.89, Willemstad Light 2.99). "Active" label (:185, 12px `text-primary`) 17/28 under 4.5 with 3 under 3 (Zettlr Frankfurt Dark 2.58, Karl-Marx-Stadt Dark 2.60, Berlin Dark 2.96), and since you hover the current theme's row most often this is the common case; the active CheckIcon (:216) has the same 3 themes under 3.
2. **"Active"/"Installed" labels and primary links at rest (medium).** AppearanceSection.svelte:185,:295 `text-meta text-primary` on `bg-setting-item-bg`: 6/28 under 4.5 (Sakura `#bd4776` on `#eedede` 3.73, Shimmering Focus Light 4.08, Willemstad Dark 4.18 with Lc30, Zettlr Berlin/Bordeaux/KMS Light 4.19-4.32). Todoist link (TodoistSection.svelte:91, dialog bg) 4/28 (Sakura 4.15, Twilight Violet Lc35). Cause: `readableCore` lifts primary only against the editor bg (theme-builder.logic.ts:186).
3. **READABILITY_PAIRS has no Settings surface and no destructive-text pair (medium, tooling).** See the table above. Root cause for findings 1, 2, 8 and the Settings share of scout 01's `text-destructive` finding. Fix: add pairs for mutedForeground, primary and destructive on settingsHoverBg, settingItemBg, settingsDialogBg, muted; add settingsText/foreground on the other Settings surfaces so they stay green.
4. **User-created, edited and imported themes bypass every contrast check; catalog themes are untested (medium, tooling).** See the tooling table: proven 1.00 to 1.26:1 after a normal import. Also the "holds for every pair" test (theme-builder.logic.test.ts:248) covers 2 of 28 themes and the themes repo CI has no contrast step. Fix: run `withReadableContrast` (or a warning in ThemeEditor/ThemeColorRow showing the ratio of the edited token against its surface) on import, save and edit; extend the test and the repo `validate` script to all published themes.
5. **primaryForeground labels read poorly by APCA (medium).** button.svelte:10 `bg-primary text-primary-foreground` is the Settings primary button: Save in the theme editor, catalog Install/Update, "Restart to update" (UpdateSection.svelte:302), the selected Rail style (LayoutSection.svelte:59). WCAG passes in all 28, APCA does not: Willemstad Dark `#090909` on `#567f83` 4.51 Lc33, Zettlr Berlin Light `#030305` on `#12865e` 4.51 Lc33, Twilight Violet 4.95 Lc39, Zettlr Frankfurt Dark 4.54 Lc41, Karl-Marx-Stadt Dark 4.56 Lc41 (5/28 under Lc45, 10/28 under Lc60); picking white or black by APCA would give Lc57 to 77 on the same fills. Hover `hover:bg-primary/90` over the row adds 8 themes under 4.5 (Willemstad Dark 3.94, Frankfurt Dark 3.90). This is the owner's black-on-saturated-mid-tone class. Cause: theme-builder.logic.ts:194 only nudges the author's primaryFg to 4.5 with `ensureContrast`.
6. **Small muted text under Lc45 in Settings (medium, APCA).** Descriptions (SettingItem.svelte:28, 12px), section labels (11px uppercase, app.css `section-label`), Sentry/Todoist/AutoOrganize paragraphs, input placeholders and inactive ThemeEditor tabs use `text-muted-foreground`, which passes 4.5 but is Lc37 to 44 on KokoBrain Default (44 on dialog), Twilight Violet (38 to 40) and the five Zettlr dark themes (39 to 42): 6/28 for descriptions, 7/28 on dialog bg. Cause: `mutedFg` lifted to WCAG 4.5 only (theme-builder.logic.ts, readableCore). Themes can fix it too (their `mutedFg`).
7. **Muted text and icons on `bg-muted` chips (medium).** TrashSection.svelte:68 count pill (11px), AutoOrganizeSection.svelte:266-272 excluded-folder chip ("missing" label and the remove X, a labelled button): 14/28 under 4.5, 5 under 3 (Zettlr Bordeaux Dark `#8f8f98` on `#505050` 2.52, other Zettlr dark 2.58, Lc27 to 28; Zettlr light 3.68, Twilight Violet 3.87). `--muted` is the palette `hover` color. (Scout 01 listed the Trash pill; the AutoOrganize chip is new.)
8. **Text-destructive errors in Settings (medium, repeat of scout 01 with Settings numbers).** UpdateSection.svelte:309, SentrySection.svelte:75, TodoistSection.svelte:151, SearchSection.svelte:122, ThemeEditor.svelte:145: inside a row (Update error) 12/28 under 4.5 (Zettlr Bordeaux Dark 3.39 Lc27, KokoBrain Default 4.06 Lc34); the paragraphs on the dialog bg (Sentry, Todoist, Search, ThemeEditor name) 12/28 (Zettlr dark 3.01, KokoBrain Default 3.08). No finding row of its own, tracked under finding 3.
9. **Outline buttons and Select triggers have no visible edge in a Settings row (low).** The outline Button (button.svelte:13: `bg-background`, border `--border`; dark: `dark:bg-input/30 dark:border-input`) sits on `bg-setting-item-bg`, which is the same color: fill vs row 1.00 to 1.24 on 15/15 light themes, border vs row 1.06 to 1.60 light (Sakura 1.06) and 1.09 to 2.80 dark (KokoBrain Default 1.09). Affects "Check and download", "Releases page", "Send test event", "Load projects", Export/Import, unselected Rail style, Retry. The label identifies the control, so WCAG 1.4.11 is arguable, but the buttons read as plain text. Input and Select borders are the same token (scout 01).
10. **Theme editor color swatches (low).** ThemeColorRow.svelte:52 draws the swatch with only `border-border`; border vs dialog bg is 1.13 to 1.86 in 28/28 themes, and 27 to 49 of the ~128 tokens per theme (surfaces, borders, tints; KokoBrain Default 35) render within 1.25:1 of the dialog bg, so the swatch, which is also the picker's click target, shows as an empty outlined box. Translucent tokens are drawn composited over the dialog bg, not over the surface they are used on.
11. **Update download progress bar (low).** UpdateSection.svelte:291,298 track `bg-muted` vs row 1.00 to 2.07 (28/28 under 3), so at 0 percent nothing is visible; fill `bg-primary` vs track under 3 on Zettlr Frankfurt Dark 2.58, Karl-Marx-Stadt Dark 2.60, Berlin Dark 2.96. Transient view.

- Select.Content and Popover item states beyond `accent`/`accent-foreground` (passes 4.76).

- Mods settings and any section rendered from vault mods.
