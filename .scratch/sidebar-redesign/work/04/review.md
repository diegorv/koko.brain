## Findings

1. minor — `src/lib/features/note-action-bar/NoteActionBar.svelte:125` (and the comment at `note-action-bar.logic.ts:45-50`). The PRD orders the bar as Favorite, Organized, Neighbourhood, Raw, width, TOC, Reveal, Copy path. Raw is not foldable, and every inline foldable renders as one block after it. So adding Neighbourhood as "one more entry" to `FOLDABLE_ACTIONS`, as the comment says, would render it after Raw, in the wrong place. The fold logic leaves room for it; the render loop does not. Fix: fix the comment now, or, when Neighbourhood lands, render the foldables in two groups around Raw (for example filter `fold.inline` for `neighbourhood` before the Raw button).
2. minor — `src/lib/features/note-action-bar/NoteActionBar.svelte:65-69` together with `src/lib/core/filesystem/fs.service.ts:292-298`. `revealInSystemExplorer` catches and only logs, so a failed Reveal (file removed on disk, opener refused) does nothing visible. Copy path shows an error toast in the same situation. CLAUDE.md "Error Handling > Components" asks for user-facing errors in a toast. The behaviour is pre-existing and was reused as is (stated in the build report). Fix: show a toast in the bar when the reveal fails, for example a bar-service `revealNote(path)` that calls `revealItemInDir` and calls `toast.error` on failure, with a test for the failure.
3. minor — `src/lib/plugins/table-of-contents/TableOfContentsPanel.svelte:19-27`. The collapse on a tab switch now lives in an effect that runs only while the panel is mounted, but `expandedPath` lives in the store. Steps: open the TOC on note A, hide the right sidebar (Cmd+B), switch to B, switch back to A, show the sidebar. The section comes back expanded. Before this branch the panel's local state was dropped on unmount, so it came back collapsed. The PRD keeps "the collapse of TOC ... on tab switch". It is a rare and harmless glitch. Fix if wanted: clear `expandedPath` when `activeTabPath` changes from an owner that is always alive, or clear it in the panel's teardown.
4. nit — `src/lib/features/note-action-bar/NoteActionBar.svelte:73`. The `run` JSDoc still says "Runs a lifecycle toggle; frontmatter failures already toast", but it now also wraps Reveal, Copy path and Copy deeplink. Update the comment.
5. nit — `src/lib/plugins/table-of-contents/toc.service.ts:694-697`. `showTableOfContents` also turns on Settings > General "Table of contents" and saves it, so a user who turned the section off gets it back for good after one click. This is a stated default in discovery.md, but help page 03 ("Table of contents: show the right sidebar with the Table of Contents section open") does not say it. Fix: add a sentence to `help/documentation/03-editor.md`.
6. nit — `src/lib/core/editor/editor.service.ts:309`. The reflowed JSDoc leaves one line much longer than its neighbours. Rewrap it.
