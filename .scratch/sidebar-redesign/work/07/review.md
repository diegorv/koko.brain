## Findings

1. **minor** — `src/lib/features/rail-shell/Rail.svelte:42-43`: the active item is `bg-file-explorer-accent text-file-explorer-primary`. In the Zettlr light themes `fileExplorerAccent` is `#c8c8c8`, so the active icon reaches only about 2.7:1 (Berlin Light, `#12865e`) and 2.8:1 (Karl-Marx-Stadt Light, `#dc2d2d`), under the 3:1 non-text minimum. The classic nav selection uses `bg-file-explorer-primary/25 text-file-explorer-primary` (`TypeSidebar.svelte`, about 3.0:1 in the same themes). Fix: use the classic selection pairing, so both shells highlight the same way, and update `Rail.test.ts`.
2. **minor** — `e2e/specs/rail-shell.spec.ts:81-89`: the criterion names both the Calendar and the Tasks tabs, but the rail E2E only opens Tasks. Fix: add a Calendar-tab step (Cmd+Shift+C) that asserts `[data-right-sidebar]` has count 0.
3. **minor** — `src/tests/lib/features/rail-shell/RailNoteList.test.ts` (row menu: "adds and removes a favorite", "moves a row to the trash after confirming"): the only assertions are `toHaveBeenCalledWith` on mocked services, which docs/TESTING.md rule 5 forbids as the sole assertion. The E2E covers the resulting state, so the criterion holds. Fix: also assert observable state (for example the menu closed and the row still listed, or `fsStore.renamingPath`), or note that the E2E owns the state check.
4. **minor** — `src/lib/core/layout/AppShell.svelte:104-113`: the rail shell hides the left toggle, but Cmd+Shift+B and the command palette still flip `layout.leftSidebarVisible` (`layout.service.ts:20-21`, `global-keybindings.ts:123-124`, `command-palette.service.ts:204-205`). The rail shell gives no sign of it, so after one press in Rail, switching back to Classic shows the sidebar hidden instead of "exactly as before". This default is already documented (ticket 10 retargets the shortcut). Fix: either make the toggle a no-op while `layout.shell === 'rail'` until ticket 10, or record the risk in ticket 10.
5. **nit** — `src/tests/lib/features/rail-shell/rail-shell.boundary.test.ts:7-15`: `readdirSync` is not recursive and the regex only matches `from '...'`, so a subfolder or a dynamic `import('#lib/plugins/...')` would get past the check. Fix: walk the folders recursively and also match `import\(`.
6. **nit** — `src/lib/features/rail-shell/rail-shell.types.ts:55-74`, `rail-registry.store.svelte.ts`: registered navigators and Today sections are stored, but nothing renders them. `RailNavigator` has no position field, while the Issue says later items land "in their final positions", so rail order would follow registration order. Fix: settle the shape (position or slot) in tickets 17/19/20 when the first consumer arrives. Do not render them here.
7. **nit** — `AppShell.svelte:91`, `Rail.svelte:14`, `rail-shell.types.ts:12`: the rail item key and `Lens.kind` are plain `string`. A union or branded type for the built-in keys (`'inbox'`) would catch typos once ticket 11 persists them.
