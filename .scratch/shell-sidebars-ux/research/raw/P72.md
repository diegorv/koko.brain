## Review block

Verbatim from `.scratch/design-review/review.md:187-192`:

```
#### P72. Relationship backlinks are hidden when a note has no linked mentions
- **Problem:** The empty state checks only linked mentions, and the relationship groups render inside the non-empty branch.
- **Evidence:** BacklinksPanel.svelte:30, 61-62, 80-102.
- **Proposal:** Show the empty state only when both lists are empty, and render each group on its own.
- **Impact:** Fixes a misleading state in the typed-relationship workflow. **Effort:** S
- **Validation:** keep.
```

Scope note: the P72 block covers only the visibility bug. It does not mention a keyboard relationship picker. The "keyboard relationship picker" in the cluster name is not part of this proposal's text. The P43 empty-groups half (Relationships block in Properties) is a different surface, PropertiesView, and is not touched by P72.

## Verdict
