## Prototype

Source: `.scratch/design-review/prototypes/note-list-rail.html`, section `#p120` (lines 467-479), script `p120()` (lines 1142-1168).

- Layout: a "Vault" control row with two toggle buttons, "No cadence set" (default, empty mode) and "Configured: 3 people" (set mode). Below it, a Before/After pair, each a mock of the Today lens pane (width 250, title "Today", count 18, rule "note date is today", min height 330).
- Before (raw): the empty state is the plain text "Add _one_on_one_every to a person in Work/_people to track 1:1s". In set mode the rows are Ana Souza (3d, not overdue), Bruno Lima (12d, overdue, warning colour only), Carla Nunes (never, overdue). Each row is: user icon + name button, day label, "New 1:1" button.
- After (empty): the raw text is replaced by one muted button "Set up 1:1 tracking" with a settings icon and a chevron. Clicking it shows a toast "Opens Settings > 1:1 notes". The toast is the only behaviour; the prototype does not navigate. The "hide the section" option of the proposal is not drawn.
- After (set): day labels read "3d ago", "12d ago" and "never"; overdue rows get an alert icon next to the warning colour; rows carry a class `fx` for the focus style, described as "press Tab" to see the focus ring.
- Below the section, the prototype draws a static "Today 18" group: a "1-1 with Ana" event row and a row titled "2026-11-10". This is filler, not data.
- Interaction states covered: empty, configured, overdue vs not, never, focus. No loading or error state. The prototype's icon keys (`alert`, `settings`, `chevr`) were not checked against its `ICONS` object.
