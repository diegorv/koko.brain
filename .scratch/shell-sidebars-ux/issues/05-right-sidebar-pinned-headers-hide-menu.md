"Hide panel" calls `setRightPanelVisible(panel, false)` from ticket 01; Properties also has "Configure types..." (`settingsPanelStore.open('types')`). ## Original proposal

- **P43.** Properties is a tall static section that pushes TOC and Backlinks below the fold, with empty Relationships chrome. Make Properties collapsible, remember the state, and make section headers sticky. Replace the empty groups with one "Add relationship" row, and render a group only when it has links. Validation: keep. (Sticky, collapse and remember are built here; the Relationships half is ticket 09.)
- **P177.** Right-sidebar section titles are indented off their own content. Keep the chevron slot. Render Info through SidebarSection. The Relationships children become 13 px sentence-case row labels. Validation: revise, the slot is what aligns the titles. (Info half here; labels in ticket 09.)
- **P123.** Info values truncate their own dates. Use a short format ("Nov 10, 2026, 10:00"); the tooltip already holds the full value. Validation: revise, dropped the "Unavailable" state.
- **P104 (header half).** Add a "Hide panel" item in each header menu, and "Configure..." for the settings that exist. Validation: revise. (Palette half is ticket 01.)
- **210 (absorbed, items 1 and 3).** NoteInfo and Relationships headings follow the sidebar section recipe: Info uses `SidebarSection` (item 1); the header flips to a heading containing a button (item 3).

## Problem

Section headers scroll out of reach, so Backlinks and Outgoing links cannot be told apart from the rows under them in a long sidebar. Properties cannot collapse, and nothing in the sidebar can hide a panel without a trip to Settings > Layout. A heading inside a button is invalid structure. Info builds its own header with an icon, so its title sits 6 px off the others, and its long dates are clipped.
