## Findings

1. minor, `src/lib/plugins/queryjs/queryjs-block-widget.ts:280-285`: a stale block whose rerun throws stays stale and runs again on every redraw until it succeeds. `execute()`'s catch never touches the stale mark, so each scroll back into view or cursor exit runs the failing script again. Before this branch it showed Run, so rule 2 of `docs/agents/live-preview-rules.md` ("never re-execute expensive code in toDOM()") is broken without limit for that block. Example: a hub block that worked, then a save changes data so the script throws.
