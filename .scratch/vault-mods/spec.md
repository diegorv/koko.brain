# Vault mods: spec

The spec for this feature is `.scratch/vault-mods/PRD.md`. Read it before building or reviewing any Issue: it holds the owner's decisions (full trust, off by default per vault, Settings > Labs, reload on save), the design decisions P1 to P10 the Issues cite, and what is out of scope.

Relay-lite hands every agent this file, not `PRD.md`; this file only points there so the decisions live in one place.
