## Findings

1. minor — `src/tests/lib/architecture/layer-rules.test.ts:27,77` — the size check is a fixed ceiling (`<= 58`), so once sidebar 24/25 delete their stale lines, a later change can add the same number of new violations together with their baseline lines and every assertion still passes: the count never ratchets below 58. The "never grows" test name claims more than it checks. Fix: either have whoever deletes stale lines also lower `LANDING_BASELINE_SIZE` (an exact `toBe` with a message saying so), or rely on the Issue's reviewer rule ("a diff that adds to `layer-baseline.json` gets changes requested"), which the main session still has to add to the relay-lite rules before this lands; until then, nothing catches a swap.
2. nit — `scripts/import-graph.mjs:272` — the CLI guard compares `resolve(process.argv[1])` with `fileURLToPath(import.meta.url)` without resolving symlinks, so running the script through a symlinked path (for example `/tmp/...` on macOS, which is `/private/tmp`) prints nothing and exits 0. It works for in-repo use. Fix: compare `realpathSync` of both sides.
3. nit — `scripts/import-graph.mjs:212` — the stale-entry message prints `\t"<entry>"`, but in the file every line except the last ends with a comma, so the printed text is not literally the file's line. Harmless for a person deleting the line; optionally say "the line containing".
4. nit — `scripts/import-graph.mjs:150` — `src/lib/contracts/` is open to every layer, but nothing constrains what `contracts/` itself imports, so a contract that imported `features/` or `plugins/` would let every layer reach them transitively without a violation. The Issue does not specify this, so it is out of scope here; Issues 08-11 should add a contracts outbound rule when the folder appears.
5. nit — `scripts/import-graph.mjs:57` — the builder already flagged that `SCRIPT_RE` would treat a `<script>` inside an HTML comment in markup as code, and `[^>]*` would cut a `generics="…>…"` attribute short. Neither occurs in src/lib today (probed), and a false extra edge would show up as a ratchet failure, not a silent pass.

## Resolution

1. Fixed. `layer-rules.test.ts` now asserts the exact size (`toBe(BASELINE_SIZE)`, renamed from `LANDING_BASELINE_SIZE`) with a message saying to lower it after deleting lines and never raise it; the stale-entry message also tells the reader to lower `BASELINE_SIZE` by one. A swap of deleted entries for new ones now needs a visible edit to the constant.
2. Fixed. The CLI guard compares `realpathSync` of `process.argv[1]` and the module path. Checked: running the script through a symlink in a `mktemp -d` dir (macOS `/var` -> `/private/var`) prints the same 58-entry baseline.
3. Fixed. The message now reads "Delete the line containing this entry from ...".
4. Rejected for this Issue: `contracts/` does not exist yet and the Issue does not specify its outbound rule; Issues 08-11, which create the folder, should add it.
5. Rejected: neither case occurs in src/lib (probed by the review), and a false extra edge fails the ratchet loudly instead of passing silently, so handling it now is speculative.
