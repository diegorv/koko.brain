# 111: Quick filters on status, due and priority

**Origin:** `tasks-view` Issue 07, moved here on 2026-11-08. Its PRD, raw evidence and closed siblings stay in `.scratch/archived/tasks-view/`. Bare Issue numbers in the text below use that feature's numbering; `priority-2026-11-08.md` in this folder maps them to the numbers here.

**What to build:** The three date chips filter on the note file's mtime (`tasks.logic.ts:76-88`, `TasksView.svelte:31-35`, `:107-117`), not on any task date, and the only other filter is the hide-completed eye (`:121-135`). Replace both with quick filters on task data (PRD assumption A2).

The quick filter state is `quick: { show: 'open' | 'closed' | 'all'; statuses?: TaskStatus[]; due?: DueRange; priorities?: TaskPriority[]; search?: string }` (PRD "One query model"), with `type DueRange = 'any' | 'overdue' | 'today' | 'next7' | 'none' | 'edited7' | 'edited30'`. Defaults: `show: 'open'`, everything else unset (an unset `due` means `any`).

- **Status menu** (a `DropdownMenu` from `#lib/components/ui/dropdown-menu/`, trigger text `Status: <value>`, where the value is `open`, `closed`, `all` or the chosen statuses joined with `, `). A radio group Open (default) / Closed / All sets `show` and clears `statuses`; below a separator, one checkbox item per status (the seven words of `statusGlyph`, Issue 05) toggles it in `statuses`. A non-empty `statuses` wins over `show`. Replaces the eye toggle.
- **Due menu** (trigger `Due: <value>`): a radio group Any (default), Overdue, Today, Next 7 days, No date; a separator; Note edited in the last 7 days, Note edited in the last 30 days. Meanings, with `today` as `YYYY-MM-DD`: overdue is due before today; today is due on today; next 7 days is due from today through today + 7 days, both ends included; no date is no `dueDate`; the two edited options keep today's rule on the note's mtime (`filterByDate`, `tasks.logic.ts:70-88`) and ignore task dates.
- **Priority menu** (trigger `Priority` when empty, `Priority: <levels>` otherwise): one checkbox item per level, in the order highest, high, medium, no priority (`none`), low, lowest. Empty means any.
- **Search:** an `<input type="search" placeholder="Search tasks" aria-label="Search tasks">` in the toolbar that sets `quick.search` on every input (no debounce; it filters in memory). It matches the task description or the note title, case-insensitive substring.
- **Reset** (a text button) shows when status, due, priority or search differs from its default, and restores all four.
- **Narrow pane:** below 560 px container width (the root is `@container` since Issue 05) the three menus fold into one `Filters (n)` dropdown holding the same three groups, where n counts status, due and priority when not at default. The search box stays visible.
- The section-tag textbox stays until Issue 13.
