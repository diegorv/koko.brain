# 014: Backlinks and Outgoing links always show the open note's own links, also after returning to a note seen at the same index version

**Origin:** `audit-2026-11-05` Issue 12, moved here on 2026-11-08. Its PRD, raw evidence and closed siblings stay in `.scratch/audit-2026-11-05/`. Bare Issue numbers in the text below use that feature's numbering; `priority-2026-11-08.md` in this folder maps them to the numbers here.

**What to build:** Both panels skip their IPC on a per-path memory of the last fetch, while each panel writes one shared store, so returning to a note leaves the store holding another note's data (or the empty reset state). Backlinks: lastFetchedBacklinksVersion (src/lib/features/backlinks/backlinks.service.ts:19) remembers every path's version, and fetchBacklinksV2Inner returns early at :142-150 when that path's version matches. It is cleared only by resetBacklinks (:257-263, vault teardown). The layout's 150 ms tab-switch fetch (src/routes/(app)/+layout.svelte:105-141) runs for A and then for B, so the store holds B's mentions. On the return to A both the layout fetch and the expand fetch (BacklinksPanel.svelte:20-30) are skipped, and the panel renders B's linkedMentions (:68-82) under A. Outgoing links: lastFetchedOutgoingKey (src/lib/features/outgoing-links/outgoing-links.service.ts:16) is keyed `${version}:${contentLen}:${path}` per path (:65-70). OutgoingLinksPanel.svelte:30-36 empties the store on a tab change but leaves the key map alone, so re-expanding A skips the IPC and shows 'No outgoing links' (:64-65). Fix direction: the skip may only fire when the store currently holds this path's data at this version, for example by keeping a single 'last written' (path, version[, content length]) record that every store write and reset updates, instead of a per-path history. The burst-save dedupe the cache exists for (repeated calls for the same path at the same version) must keep eliding the IPC. Read docs/agents/indexing-watcher-rules.md item 2 before changing the panels.

A cache hit then means 'this path was fetched at this version once', not 'the store holds this path's data now'.
- Backlinks: `fetchBacklinksV2Inner` (src/lib/features/backlinks/backlinks.service.ts:141-150) returns early when `lastFetchedBacklinksVersion.get(path)` (Map at :19, set at :164) equals the current version.
