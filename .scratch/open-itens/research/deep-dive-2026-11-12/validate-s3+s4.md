## Rejected additions

- **061 part 3 (TSV paste in fences and indented lines) as an equal-rank item.** The bug is present (`paste-tsv-handler.ts:19-40` has no context check, and `paste-tsv.logic.ts:19-26` accepts a leading empty cell). s3's trigger is wrong, though. It says the owner uses a "tab-indented editor", but the editor sets no `indentUnit` (`setup/editor-extensions.ts`, only `indentWithTab` at `:165`), so it falls back to CodeMirror's two spaces (`node_modules/@codemirror/language/dist/index.js:808-811`). Nested list lines copied from the app are not tab-indented unless the note already has tabs. What is left is pasting tab-indented code (for example from this repo, which uses tabs) when the first copied line starts with a tab. Low-medium, medium risk (paste plus live preview). Keep it as a second pass after part 2, not with it.
- **061 part 1 (fence info string lost on a language switch).** Present, but it needs an info string such as `title=`, which the owner's workflow does not show. It also touches the `SPECIAL_LANGUAGES` keying (medium risk). Defer.
- **057 (clearing search shows a stuck Searching...).** Present (`search.service.ts:128-135` returns before `setSearching(false)`; `:271-274` is gated on version; `SearchPanel.svelte:115-118` shows Searching... before the empty hint). Search is not in the owner's daily list, the panel self-heals on the next query, and the fix is one line. Impact is low, so it is not queue-worthy. Take it only as a drive-by when search is touched.
