# Design review: Tasks view (src/lib/features/tasks)

Evidence: tasks-all-open-light.png / -dark.png, TasksView.svelte (1213 lines), TaskLists.svelte, SourcesPanel.svelte, tasks.store.svelte.ts, tasks.logic.ts, task-query.logic.ts.
Checked and dropped: the inventory worried that an error before first load hides the alert behind "Indexing tasks...". tasks.service.ts:92-99 sets `hasLoaded` in `finally` on failure too, so the alert shows. Not a bug.

## Clear improvements

1. Overdue and today tasks are buried in a note-alphabetical list. Default "All open" groups by Note, ordered by path (task-query.logic.ts:245 `compareTaskPaths`); the sort keys due/priority/path apply only to non-Note groups and "no control sets it" (tasks.store.svelte.ts:39). In the screenshot "Overdue follow-up" (Nov 5) sits mid-list under 2026-11-10. Only two built-in lists exist (All open, No date: task-views.logic.ts:93). Proposal: add a built-in "Today" list (overdue + due today, grouped by Due date), a clickable "N overdue" badge in the toolbar that sets Due: overdue, and a Sort submenu in Display.
2. Row actions sit about 800px from the task text. List content is full pane width (TasksView.svelte:1076 `p-4`, row `w-full` at 812); the "..." (890) is at the far right edge while text starts at ~640px (screenshot). Eye travel and mis-clicks on adjacent rows. Proposal: cap the list column at about 760px (max-w-3xl, left-aligned), or move chips and actions next to the text and reveal "..." on row hover/focus-within (keep it always focusable).
3. Note group headers cost three lines for one or two tasks. Header = chevron, icon, title, "N of M open", then a folder subtitle line (756-780) plus `mb-2` and `space-y-6` between groups (1135). In the screenshot 6 of 8 visible groups have 1-3 tasks, so headers outweigh content and fewer than 14 tasks fit on screen. "2 of 2 open" is noise when open equals total. Proposal: one-line header (chevron, icon, title, folder in muted text after the title, count only when open differs from total or as a plain number), `space-y-3`.
4. Overdue is signalled weakly. Only the 12px calendar icon turns red; the label stays foreground (TasksView.svelte:872-874); chips are 11px `text-label` muted (869), identical to scheduled, recurrence, tag and priority chips. No "today" emphasis and no relative wording (chipDate, tasks.logic.ts:130 gives only "Nov 5"). Proposal: overdue chip gets destructive text plus "5d overdue" (title already says Overdue); due-today chip uses primary; priority chip gets a small colored flag icon (high/highest) instead of plain text.

## Moderate

5. Active filters are not visible. All five filter triggers share one static class (999, 1016, 1033, 1050): a chosen Priority or Tag changes only the label text, "Status: open" and "Due: any" look the same as a modified filter. Proposal: non-default trigger gets `bg-accent text-foreground` plus a dot or count; "Reset filters" stays.
6. Display menu is incomplete and inconsistent. "Heading" is a separate RadioGroup placed after the Property submenu (957-959), visually outside "Group by"; the trigger always says "Display" so current grouping is invisible; there is no sort (see 1). Proposal: put Heading with the other options, Property submenu last; trigger shows "Group: Note"; add a "Sort by" section.
7. Sources panel exposes AND/OR logic as jargon. Copy "A task is listed when every clause of one card matches" (SourcesPanel.svelte:348); cards are stacked with no "or" divider (350-351); "Remove card" has no undo; exclude sections show 8 switches and 8 inputs, twice (279-340). Proposal: label cards "Match any of" with an "or" separator between cards, "all of" per card, collapse the Global excludes section by default.
8. Rule sentence, "Edit", "Clear" and the "modified" marker are cryptic. A 12px sentence (1085) with bare "Edit" (1094) and "Clear" (1098, silently empties all sources, no confirmation or undo); marker is lowercase "modified" with Save as view / Reset on built-ins and Save / Revert on saved lists (TaskLists.svelte:246-256). Proposal: "Edit sources", "Clear sources", "Unsaved changes" with the same two verbs everywhere (Save / Discard).
9. Three rows of chrome before the first task: toolbar (h-10), filter bar (965), sentence row (1084); first task at y=217 of 900 in the screenshot. Proposal: put search into the filter row, show the sentence only when Sources are customised (or in the Sources button tooltip).
10. Search field is hard to see and use. `placeholder:text-muted-foreground/50` at 12px (921) is below contrast minimum; focus is border-only (`focus:border-primary/50`), h-6 w-40; Escape does nothing and there is no shortcut to focus it (tasks-keys.logic.ts handles only arrows, Home/End, Space, Enter, menu). Proposal: shadcn Input styling with the 3px ring, Escape clears, Cmd+F or "/" focuses when the Tasks tab is active.
11. Hidden "Hide this note / folder / type" actions. Group rule actions are `opacity-0` until header hover or focus (734), and they edit the list's exclusions with no toast or undo; the only feedback is the "modified" marker. Proposal: always-visible "..." on the header with those items, plus a toast "Hidden Health. Undo".
12. Setting due date or priority is deep. Row menu (676-712) puts Due and Priority in submenus, and the row keys offer only toggle, open and menu. For a daily triage flow, rescheduling 10 tasks needs 3 clicks each. Proposal: row keyboard shortcuts (for example `d` opens the due submenu, `1`-`4` priority) and show hints in the menu; add Tomorrow/Next week as first-level buttons.
13. Inconsistent focus styling. Filter triggers (928-1050), Reset filters (1064), Edit/Clear (1089, 1097), Retry (609), empty-state action (1117), wikilinks (846), marker buttons (TaskLists.svelte:74) have no `focus-visible` ring, while row controls use `ring-[3px] ring-ring/50`; the only fallback is the UA outline recoloured by app.css:486. Proposal: one shared class (or use shadcn `Button variant=ghost size=xs`) for all text buttons.

## Polish

14. Dimmed rows (`opacity-60`, 812) are context parents of matches with no label; users may read them as disabled. Proposal: tooltip "Shown for context" or a thin left rule instead of opacity.
15. Loading is plain text (1080) and the spinner (912) is unconditional (no `motion-reduce:animate-none`; no `prefers-reduced-motion` anywhere in the folder). Proposal: 3 skeleton group headers and `motion-reduce:` classes.
16. Copy drift: "Next 7 days" (109) vs "In a week" (549) vs "This week" (task-query.logic.ts:905); "None" vs "No priority"; "Show all" vs the Status menu; calendar emoji inside the empty hint (task-query.logic.ts:1430). Proposal: one glossary pass.
17. List column is 176px wide (TaskLists.svelte:178) for three entries, one of them "To list 0"; combined with the shell rail and note list it narrows the task pane. Proposal: tabs or a segmented control above the filter row (the menu variant already exists below 720px).
