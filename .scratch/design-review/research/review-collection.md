# Design review: Collection (tables / views)

Scope: src/lib/features/collection plus its live-preview widget. Evidence: code (file:line) and screenshots collection-and-queryjs-block-light.png, view-file-table-light.png.

## Clear
1. Widget table breaks words mid-word and has no horizontal scroll (collection-block-widget.ts:432-471; styles.ts:595-605; screenshot collection-and-queryjs-block-light.png shows "priori ty", "owne r", "Dieg o", dates wrapped). The Svelte table uses whitespace-nowrap (CollectionTableView.svelte:61), the widget does not. Propose: scroll wrapper (overflow-x auto), nowrap cells, ellipsis on long text with title, header row never wraps.
2. Toolbar icon buttons have no name, tooltip, or counts (CollectionView.svelte:595-670). Sort, Filter, Properties, Calendar are four unlabelled glyphs; activeFilterCount is computed (:222) but never rendered; Properties never shows active state. Propose: aria-label + tooltip with shortcut-free label, count badge for filters and sorts, dot when columns are hidden.
3. Raw column headers and ".md" in the file column (collection.logic.ts:476 falls back to the key; view-file-table-light.png shows "file.name", "Kokobrain Launch Plan.md"). Propose: built-in friendly names (Name, Modified, Created, Folder, Tags), strip extension, render name as the note title.
4. Header click accumulates sorts silently (CollectionView.svelte:397-409): clicking column B after A adds a secondary sort, third click removes it; only an arrow glyph shows (CollectionTableView.svelte:27-31). Propose: plain click replaces the sort, shift-click adds, show rank number on multi-sort, aria-sort.
5. Calendar views drop undated records without telling (calendar.logic.ts:109-111 `continue`), while the toolbar still says "N results" (CollectionView.svelte:587); empty calendar renders a bare grid (CollectionCalendarView.svelte, no empty branch). Propose: "N without date" chip with a popover list, and an empty-state line.
6. Live-preview block shows only the first view (collection-block-widget.ts:110 `views[0]`), with no cue that more views exist. A dashboard block with Projects + Calendar views hides the second. Propose: compact view switcher in the block header (same tab chips as the full view), or at least "+N views".
7. Empty and loading states are dead ends (CollectionTableView.svelte:34-37, CollectionView.svelte:509-512, widget :160-166): same text for "no notes" and "filters exclude all", no recovery action, no spinner. Propose: distinguish both cases; filtered case gets "Clear filters" and "Edit filters" buttons; loading gets a skeleton rows placeholder.

## Moderate
8. Nested button-in-button toolbar triggers (invalid HTML, double tab stop, UA focus ring only): PopoverTrigger/DropdownMenuTrigger wrapping Button/button without `child` snippet (CollectionView.svelte:594-602, 621-627, 644-650; SortPanel.svelte:98-105; FilterRow.svelte:114-121; CalendarConfigPanel.svelte:51-58). bits-ui renders its own `<button>` when no child snippet (popover-trigger.svelte). Propose: use the `child` snippet like the context-menu trigger (:521) and give all triggers focus-visible ring.
9. View tabs hide their actions: rename = double-click, delete / change type = right-click only (CollectionView.svelte:537, 554-584); delete is disabled at one view with no explanation. Propose: tab chevron on hover/active opens the same menu; type icon on each tab; disabled item gets a tooltip.
10. Table rows and headers are not keyboard reachable (CollectionTableView.svelte:44-47, 55-58): th and tr have onclick only. Link inside a clickable row bubbles to the row handler (:67-68). Propose: headers as buttons, rows focusable with Enter to open, stopPropagation on links.
11. Conjunction selector looks like plain text (FilterPanel.svelte:113-115, 175-177): no chevron or border, so the and/or/not choice is undiscoverable. Propose: the same bordered select trigger used in FilterRow.
12. Sort rows: drag without drop indicator, no keyboard alternative, role=listitem without list, delete icons unnamed (SortPanel.svelte:80-92, 126-133). Propose: insertion line during drag, move up/down via buttons or Alt+arrows, aria-labels.
13. Columns cannot be reordered in the UI (PropertiesPanel.svelte:79-84 checkboxes only; handleColumnsChange CollectionView.svelte:392 persists order but nothing edits it). Propose: drag handles in the Properties panel, same pattern as sort rows.
14. Table has no sticky header, no column width control, no truncation (CollectionTableView.svelte:41-52, 61): a 200-row table loses its headers on scroll and long text widens the table. Propose: sticky thead, max-width cells with ellipsis, optional resize.
15. Linear calendar bars force text-white on any color (CollectionLinearCalendarView.svelte:199) while the widget already picks readable text with barTextColor (linear-calendar.logic.ts:302). Propose: reuse barTextColor in the Svelte view.
16. Icon-only controls without names in panels: formula pencil/delete (PropertiesPanel.svelte:133-146), FormulaRow X (:57-59, 87-89), FilterRow delete (:101-103, 184-186), calendar nav buttons title-only. Propose: aria-label on all, aria-hidden on icons.

## Polish
17. Copy drift: "Parse Error" vs "Filter error" (CollectionView.svelte:505, 691), "..." vs ellipsis character, "Previous/Next" vs "Back/Forward" (linear calendar :91, 119), "+N" vs "+N more" and 2 vs 3 events per cell between widget and Svelte calendar (widget :249-261, CollectionCalendarView.svelte:36).
18. Hard-coded text-[11px] where text-label exists (CollectionCalendarView.svelte:154, 162; linear :146, 151); duplicated trigger/input class strings in 7 places; tab rename input has no ring (CollectionView.svelte:530).
19. `now` captured once per mount so the today highlight does not move at midnight (CollectionCalendarView.svelte:38); smooth scroll ignores reduced motion (PropertiesPanel.svelte:68-70); text-muted-foreground/50 icons at rest are low contrast (FormulaRow.svelte:81, SortPanel.svelte:90).
