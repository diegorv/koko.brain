# Design capture manifest

Source: zz-design-capture.spec.ts (copy at ../research/zz-design-capture.spec.ts), run in .claude/worktrees/design-capture, 1440x900, browser E2E mode with Tauri mocked.
Themes: light = built-in "Lavender Haze" (the only light built-in), dark = "KokoBrain Default". Fixed clock 2026-11-10 10:00 Europe/Berlin. Vault: 37 notes (projects with _type, meetings, people, daily, 3 unorganized inbox captures, 13 events, kanban, canvas, .view, dashboard with collection + queryjs).
Caveats of the harness: every note shows "just now" (mock mtimes, so Today lists all 18 notes); the Settings toast "Could not load the theme catalog" is the offline mock (no network), but the same toast appears on any offline machine; the vault uses the test vault pane sizes unless stated; editor font is the test vault's MonoLisa fallback (monospace).
