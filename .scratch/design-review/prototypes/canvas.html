P12

Canvas colours are dark-only: edges, grid, minimap and overlays vanish or turn heavy in light themes

clear

Problem. The xyflow variables and overlay chrome use hard-coded white or black alpha, so edges, grid and node borders are near-invisible in the Lavender light theme and the minimap is a dark slab.

P13

Canvas groups and edges cannot be labelled from the UI

clear

Problem. Groups are created with an empty label, the 12 px muted label is invisible when empty, and "Edit label" is never wired, so edge labels only exist in JSON.

P07

A corrupt or half-edited canvas JSON shows as an empty board, and the next edit overwrites the file

moderate

Problem. parseCanvas swallows the parse error and returns an empty canvas. The first add, move or delete then persists over the broken text, so a hand-edited file is lost silently.

P133

New canvas cards are not ready to type into and stack on each other

moderate

Problem. A new text card is neither selected nor in edit mode, and every toolbar add lands on the same viewport centre, so repeated adds stack exactly.

P135

Canvas text cards are hard to enter and cramped once editing

moderate

Problem. Editing needs a double-click. The textarea is 40 px tall with its own vertical resizer and no outline, competing with the node resizer.

P134

A single click on a canvas file or link header navigates away

moderate

Problem. The header is the natural grab spot, yet a plain click opens the note or URL. The open icon only shows on hover and a failing URL gives no feedback.

Docs follow-up

  • Update 11-canvas.md:85: "click the header to open" becomes "click selects, Cmd+click or the icon opens".
P31

Hand-built overlays do not move, trap or restore focus, and Escape is inconsistent

moderate

Problem. The canvas menu is a plain div of buttons: no roles, no arrow keys, focus stays where it was, and Escape does not close it. The file picker silently caps at 20 results.

Implementation path

  • Rebuild the pane, node and edge menu on bits-ui ContextMenu (roles, typeahead and focus come for free), or at minimum add the roles and key handling shown here.
  • File picker and link input move to Command/Dialog with a labelled input and a result count.
  • Settings sheet changes from the same proposal (focus in, focus restore, Escape guard) are outside this canvas group.
P136

Canvas connection handles are hidden until hover and only 8 px

polish

Problem. Handles show only on node hover with an 8 px target, and image nodes expose just four one-way handles (top in, bottom out, left in, right out).

Scope

  • Handle ids and the JSON Canvas side mapping stay as they are. Only visibility, hit size and ImageNode's missing handles change.
  • Dropping an edge on empty canvas still creates a connected card.
P137

Canvas file and image cards give weak or stale status

polish

Problem. Image cards use one placeholder for loading and error, put the full vault path in alt and crop with object-fit: cover.

One switch drives both panels.

Dropped from the proposal

  • A named-file error on note cards and extra Open/Remove buttons: the header already names the file and the context menu has Delete.
