Throwaway prototypes for the note list column and the rail. Tokens, type scale, radius and elevation are copied from src/app.css and the default light theme. BEFORE screenshots come from the real app and are light only; every BEFORE recreation and every AFTER recreation follows the theme toggle. Headers in the sections after P84 show the proposed header on both sides; only the body differs. Ordered by tier: clear problems first, polish last. Everything is interactive: click, right-click, use the keyboard.

P33

The note-list header loses New note and Daily note at narrow widths

clear

Up to eight shrink-0 controls sit in a clipped 40 px band and the + is the first to disappear; the sort, properties and archive glyphs are ambiguous without a tooltip.

AFTER: Search, Filter and + stay pinned. Sort, Properties and Archive fold into one Display popover. Below 220 px the Display and daily-note controls move into a single overflow menu. At 150 px the title keeps about 38 px, so it truncates; the rule line below the header already repeats the folder name and the full title is a tooltip. Drag the slider for any width.

P39

Note actions are split across five surfaces, and Inbox triage means opening every note

clear

Mark organized and Archive exist only for the active note. The row menu lacks Archive, Organized, Move and History, the tab menu has only Pin and Close, and one action is labelled both "Delete this note" and "Move to Trash".

AFTER: one note-actions list (same labels, same order) in the row menu, the More menu, the tab menu and the palette. The tab menu adds Close others and Close to the right. Inbox rows get an inline organized check, so triage is one click per row. Try it below.

P84

Active filter, sort and display state is shown by colour only

moderate

A changed filter only tints its icon, the Archive icon looks the same at every setting, and nothing says why notes are missing.

AFTER: the Filter trigger shows a count badge, the Display trigger shows a dot when any display option (including Archive) is not at its default, a strip under the header says what hides notes and offers Clear filters. Open both headers, pick filters or an archive mode and compare. Tasks and Graph already show values as text, so they stay as is.

P24

Lists have no keyboard model, and every row is its own Tab stop

moderate

Each note row is a separate Tab stop, there are no arrows, and in search the first Escape only blurs. Kanban already has a model, so it stays as is.

AFTER: one Tab stop for the whole list (roving tabindex), Up and Down, Home and End, Enter to open, Cmd+Enter for a new tab, F2 to rename. In search, ArrowDown goes from the input to the first result and the first Escape clears the query. The hint bar shows while the list has focus. Click inside a list, then press Tab and the arrow keys.
