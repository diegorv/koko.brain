Clear improvements

P43

Properties collapses, section headers stick, and empty Relationships shrinks to one row

ClearEffort M

Problem. Properties is a static section, and an empty Relationships block adds about 120 px on every note, so Table of contents and Backlinks fall below the fold and headers scroll away. Proposal. Collapsible Properties with remembered state, sticky headers, and one "Add relationship" row that becomes grouped links only when a group has links.

P45

Untyped notes get a "Set type" row, and Add property asks for a key and a type

ClearEffort M

Problem. The type row exists only when _type exists, new properties are always text, and the row icon is not a control. Proposal. Always show the type row, let the row icon open a type menu, and add a type picker to the Add property form.

P72

Relationship backlinks show even when a note has no linked mentions

ClearEffort S

Problem. The empty state checks only linked mentions, so a note with only typed relationship backlinks says "No backlinks found" and hides real data. Proposal. Show the empty state only when both lists are empty and render the two groups independently.

Moderate improvements

P121

At narrow widths the key sits above the value instead of being cut to "t..."

ModerateEffort M

Problem. Key, value and a reserved remove button squeeze each other, plus a 16 px spacer on the type row. Proposal. A container query stacks key over value below about 220 px, and the remove button leaves the flow (it overlays the row on hover). Drag the slider.

P74

Link rows have two lines and clean snippets

ModerateEffort M

Problem. Path, alias and heading share one truncated line, and snippets are raw markdown (# Roadmap Linked from [[Welc...). Proposal. Title, then a muted folder and heading line with a path tooltip; snippets lose # and [[ ]] and clamp to two lines.

P115

The TOC highlights the current heading and drops its decorative chevrons

ModerateEffort M

Problem. Chevrons do nothing, there is no current-heading cue, and no palette command. Proposal. Remove the chevrons, add scroll-spy with aria-current, and a "Go to heading" palette command. Scroll the note on the left. The existing collapse on tab switch is deliberate; keeping the TOC open across tabs is an owner decision, not part of this prototype.

P71

Backlinks (and Outgoing links) stay open across note switches

ModerateEffort M

Problem. Both panels collapse on every path change. Proposal. Remember open or closed; while open, refetch for the new note; while closed, fetch nothing (so no count badge on collapsed headers, which would need an eager fetch). Switch notes and watch the fetch counters.

P44

A refused property rename or add reverts and says why

ModerateEffort S

Problem. The key input keeps text that was never saved, with no Enter or Escape. Proposal. Enter commits, Escape reverts, a duplicate or blank key reverts, and a duplicate shows an inline message. Try renaming status to priority, then try Add property with owner.

P46

The relationship picker works from the keyboard and lists recents first

ModerateEffort S

Problem. Only Escape works, selection is mouse-down only, and an empty query shows the first 20 files alphabetically. Proposal. An active row driven by Up and Down, Enter to pick, aria-activedescendant on the input, and recent files first, like the Quick Switcher.

Polish

P75

Unresolved outgoing links become create buttons in a "Broken links" group

PolishEffort M

Problem. Unresolved links are dead, dimmed red rows with no action. Proposal. Group them under "Broken links", make each a button that creates the note, and drop the opacity. Click one.

P122

Chips edit in place on double-click, and an empty list shows "+ Add"

PolishEffort M

Problem. Chips are static, so a typo means delete and retype, and an empty list shows only the key. Proposal. Double-click a chip to edit in place (Enter or blur saves, Escape cancels); an empty list shows a visible "+ Add" chip. Enter in the add field still keeps it open.

P123

Info dates use the short format and fit

PolishEffort S

Problem. "November 10, 2026, 10:00" is clipped to "November 10, 2026, 1...". Proposal. Use "Nov 10, 2026, 10:00"; the full value stays in the existing tooltip (hover a value). At very narrow widths the value wraps under its label instead of clipping.

P177

The Info header matches its siblings, and Relationships children use sentence-case labels

PolishEffort S

Problem. Info hand-rolls its header with an icon, so its title starts at a different x, and Relationships plus its three children are identical uppercase labels. Proposal. Render Info through the same section header (keep the chevron slot), keep "Relationships" as the group label, and show children as 13 px sentence-case muted labels. Toggle the alignment guide.
