# Tasks view UX: adversarial critique of synthesis.md

Read-only pass at `main` `23f6c1f91`. I read `synthesis.md` in full, skimmed the three proposals and V1 to V10, and checked the load-bearing claims against the code and the open Issues. Nothing was run. **Fact** means verified here with path:line. **Opinion** is labelled.

## Verdict

**Accept the direction, reject the ticket list as written.** The spine is right: build on the owner-answered PRD chain (108 to 113) instead of a parallel backlog, fix feel and correctness first, keep state that must survive a remount in `tasksStore`. Most code claims I checked hold (list blanking at `tasks.service.ts:67` and `TasksView.svelte:139-140`; mtime order at `src-tauri/src/vault/index.rs:1082` and `commands/vault.rs:694-697`; remount at `src/lib/app/EditorView.svelte:72-73`; the toolbar test at `src/tests/lib/pane-toolbar.test.ts:30`, `:46-50`; the bindable `viewportRef` at `scroll-area.svelte:8`, `:30`; `toggle_task_status` taking any `target` at `src/lib/contracts/commands.ts:108-111`).

The list itself has four structural problems:

1. The "untouched existing chain" is not untouched. Issue 115 waits on 111 and rewrites the fetch path that T02, T03 and T07 build on, so the parallel track and the amendments are both wrong (D1).
2. Two tickets are too big for one context window (T08, T10), and one is horizontal with no user-visible result (T01) but still blocks the first real slice (D3, D4).
3. Wave 1 puts a title and count into a 40 px toolbar that cannot wrap while the pills, eye and tag box are still in it. The synthesis's own mockup line overflows its frame (D2).
4. Some of it is scope the owner did not ask for, or that contradicts an owner answer: T12 against B5, "Tasks: Open", T15 (D11, D20).

The biggest gap (opinion): the plan never asks the owner whether the default `#to-list` filter can be lifted early. That filter is the main reason the view looks empty and "simple", and it is also what triggers the disk scan on every refetch. The plan leaves it to 124, about twelve tickets away (D21).
