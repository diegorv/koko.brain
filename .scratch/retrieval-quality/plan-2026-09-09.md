# Retrieval quality: hybrid candidate recall, reranker context, gap filter scaling

Fixes four verified defects in the query-time retrieval stack (`search_hybrid`,
`search_semantic`, `adaptive_filter`) and adds the eval harness needed to prove
each change improves retrieval instead of merely changing it. None of the tasks
below changes what is stored in the `chunks` table, so no `EMBED_RECIPE_VERSION`
bump and no reindex.

Each finished task is committed before the next starts.
