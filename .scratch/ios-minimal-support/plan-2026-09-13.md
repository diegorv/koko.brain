# Minimal iOS / iPadOS support (markdown editor only)

Make the Tauri 2 app build and run on iPhone and iPad with the markdown editor,
file explorer and text search, without semantic search (ONNX Runtime), the
in-app updater, the quick-capture composer, global shortcuts and the native
menu bar. Desktop behaviour must not change. The Xcode project
(`src-tauri/gen/apple/`) is generated on macOS with `pnpm tauri ios init`; the
Linux container cannot run that command, so this plan prepares everything the
generator needs and documents the remaining macOS step.

## Tasks

- [ ] Task 1: Platform detection (`core/platform`): pure `detectPlatform(userAgent, maxTouchPoints)` logic + `platformStore.isMobile` getter, with tests.
- [ ] Task 2: Mobile vault: `openMobileVault()` creates/opens `$DOCUMENT/kokobrain-vaults/Notes` (app sandbox Documents, visible in the Files app); welcome page auto-opens it on mobile; tests.
- [ ] Task 3: Skip desktop-only IPC on mobile: semantic init/shutdown/incremental updates (lifecycle, search hook, note-change), auto update check; tests.
- [ ] Task 4: Settings UI on mobile: hide Update and Quick Capture sections, show semantic search as unavailable, hide the status-bar semantic indicator; tests.
- [ ] Task 5: Mobile shell layout: viewport-fit + safe-area, full-width editor with the left sidebar as a drawer (closes when a file opens), no right sidebar / resize handles on mobile; `mobile-layout.store` with tests.
- [ ] Task 6: Capabilities split by platform (desktop-only permissions out of `default.json`), `bundle.iOS` config and `Info.ios.plist` (Files app access).
- [ ] Task 7: Cargo features `semantic` + `desktop-integration` (default on, forced off on iOS/Android by `build.rs`), gate ONNX / updater / process / global-shortcut / quick-capture / menu / composer code paths and their tests; verify with `cargo test` and the mobile-profile `cargo check`.
- [ ] Task 8: CI: run the mobile-profile `cargo check` in the Rust job.
- [ ] Task 9: Docs: `docs/IOS.md` (build on macOS, vault location, limits, verification), ADR, `CLAUDE.md` and `DEV-ENVIRONMENT.md` pointers.
- [ ] Task 10: Close out: delete this plan file in its own commit.

## Notes

- `pnpm tauri ios` is not compiled into the Tauri CLI on Linux (`unrecognized subcommand 'ios'`), and `cargo check --target aarch64-apple-ios` needs the Apple SDK, so the mobile Rust profile is verified on the host with the features turned off: `cargo check --no-default-features` plus a `TAURI_CONFIG` override that drops the desktop capability.
- Verified in the cargo registry: `notify` 8.2 falls back to `KqueueWatcher` on iOS, `sysinfo` 0.39 supports iOS, `tauri-plugin-global-shortcut` is `#![cfg(not(ios/android))]`, `arboard` has no iOS backend, `tauri-plugin-updater` is desktop-only.
- On iOS `$DOCUMENT` resolves to the app container's `Documents/`; `UIFileSharingEnabled` + `LSSupportsOpeningDocumentsInPlace` expose it in the Files app so the vault can be edited or synced from there.
- Keybindings stay `meta`-based: a hardware keyboard on iPad sends `metaKey` for Cmd.
