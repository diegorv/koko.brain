## Findings

1. minor — `src/lib/features/auto-move/auto-move.logic.ts:204-205`: the type-definition gate compares the raw `_type` value to `'Type'`, but the app decides a type definition on `isA`, which Rust derives with `normalize_type_casing` (first letter uppercased, `src-tauri/src/vault/entry.rs:399-406`). A note with `_type: type` is a type definition in `typeDefinitionsStore` (`isA === 'Type'`) yet passes this gate, so an `always` `_icon`/`_color` rule would stamp it and every note of the type would inherit it. Probe: `propertyWriteSkipReason('/v/T.md', '---\n_type: type\n---\n', ...)` returns `null`. Fix: normalize the first letter before comparing (mirror `normalize_type_casing`), and add a logic test for `_type: type`. Low likelihood, since the app writes `_type: Type`.
2. minor — `src/lib/features/auto-move/auto-move.service.ts` `readCurrentContent` (tab branch, first two lines): Behavior 2 says the open tab's content wins over disk, but no test opens a tab. Every fresh-content test reads from the mocked disk, so a regression that always read disk would evaluate stale content for the most common case (the note being edited, with unsaved edits) and stay green. Fix: add a service test that opens a tab in the real `editorStore` with content that differs from the mocked disk and asserts the rule evaluates the tab content.
3. nit — `src/lib/features/auto-move/auto-move.logic.ts:200-202`: the protected-folder match is case-sensitive (`startsWith`), while `isInExcludedFolder` in the same file is case-insensitive. On a case-insensitive macOS volume, a settings value `_System` against a folder `_system` would not gate. Fix: compare lowercased, as `isInExcludedFolder` does, or leave as is and accept it.

## Resolution

1. Fixed. `propertyWriteSkipReason` compares `normalizeTypeCasing(_type)` (the TS twin of Rust's `normalize_type_casing`) to `Type`. Logic test: `_type: type` is a type definition.
2. Fixed. Service test "evaluates the open tab content over the disk content" opens a real `editorStore` tab whose content differs from disk and asserts the written frontmatter and body come from the tab. Mutation check: removing the tab branch in `readCurrentContent` makes it fail.
3. Fixed. The protected-folder match is case-insensitive, like `isInExcludedFolder`. Logic test: `_System` gates `_system/`, `Templates` gates `templates/`.
