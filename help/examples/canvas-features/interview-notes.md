# Interview synthesis — offline-first tools

Five 30-minute calls with engineers and product managers who recently
considered or rejected a self-hosted / offline note tool.

## Patterns

- Every interviewee mentioned **data portability** as the deciding factor.
- Four out of five had previously left a tool because they couldn't easily
  export. None wanted to repeat that.
- Three explicitly described "drop my markdown back into a folder" as the
  benchmark they used to decide.

## Quotes

> "I'm not switching tools again until I can pop the data out as easily as
> I put it in." — P2

> "If the format is markdown, my fallback plan is just `ls`." — P4

## Implications

- Lead with import → edit → export, not with the feature surface.
- Make the export shape literally visible in marketing — folder tree
  screenshot beats a 50-feature checklist.
