# Arrows between bullets and headings

Put the cursor on the first bullet and press ArrowDown / ArrowUp repeatedly. Expect: only the cursor line shows `#` or `-`; text does not slide; the caret lands on a sensible column.

- first bullet with some text
# Heading one right after a bullet
- second bullet
## Heading two
- [ ] a task item
- [x] a done task
### Heading three with **bold** and *italic*
1. ordered item
2. ordered item two
#### Heading four
- nested parent
  - nested child
    - nested grandchild
